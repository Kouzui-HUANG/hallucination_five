03

How We Work製作流程

  1. FRAME 01

    需求訪談

    BRIEF

    確認用途、受眾、片長、預算與交付規格。

  2. FRAME 02

    腳本與分鏡

    SCRIPT

    先把故事寫好，再決定哪些畫面交給 AI。

  3. FRAME 03

    3D 動態預演

    PREVIS

    用輕量 3D 搭出鏡頭運動與角色走位，當成生成的動態參考。

    幻五的方法
  4. FRAME 04

    角色與場景設定

    DESIGN

    先做角色設定表與場景美術，鎖住整部片的一致性。

    幻五的方法
  5. FRAME 05

    生成與篩選

    GENERATE

    每一格畫面都由人挑選、重生成與調整。

  6. FRAME 06

    剪輯・配樂・交付

    FINISH

    剪輯、配樂、字幕與調色，依平台規格交付。

AI 負責生成，導演負責判斷。工具會換代，判斷力不會。
